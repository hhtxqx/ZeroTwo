# ZeroTwo

## 项目简介：
* ## “Zero Two”是一款专注于网络安全等级保护2.0（等保2.0）合规检测的自动化平台，全面覆盖 Windows 10/11、Windows Server 以及 Linux 操作系统。本项目的设计初衷是打破传统安全检测工具操作复杂、门槛高的壁垒，通过简洁且高互动性的界面设计，在最小的视觉空间中容纳最丰富、实用且专业的功能，致力于让非相关行业人员也能轻松、独立地完成等保检查工作，打造一款兼具实用性、创新性与可扩展性的新手友好型检测工具。
* ## 在核心能力上，项目共实现了三大创新突破：一是引入大模型智能分析与正则脱敏技术，在严格保障数据隐私的前提下，一键自动生成高质量、带原始证据附录的企业级等保报告；二是构建 Web 控制台与 Agent 协同架构，实现 Windows 主控端对异构 Linux 系统的同网段无感统管与报告集中回传；三是采用雷达图直观呈现历史基线差异，并开放 SDK 支持第三方插件热插拔，同时深度融合极具视觉冲击力的《新世纪福音战士》明日香二号机专属红橙 UI 主题，完美兼顾了极客美学与工程实用性。

## 使用说明：Windows端解包exe程序压缩包（executable.zip）后以管理员身份执行（部分检查项需要使用管理员权限），Linux端需要解包并运行agent的脚本文件（deploy_linux_web.tar.gz）才能在Windows程序上的web控制台集中管理

## 特别说明：需要坦诚的是，本项目最初为大一学生的课程作业。受限于开发时间与个人经验，在底层代码实现与架构设计上难免存在不成熟与待完善之处，且后续大概率不会进行长期的更新与维护。因此，本程序主要供学习交流与轻量级参考使用，使用过程中如有遇到 Bug 或体验不佳的情况，敬请各位使用者与前辈多多包涵与谅解。
